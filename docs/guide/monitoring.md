# 用量、速度与额度

控制台列表直接显示常用统计。图标支持悬停或键盘聚焦查看解释；触屏设备可点按帮助图标。

## API Key 历史

API Keys 默认显示近 7 天，可切换近 24 小时或 30 天，按请求量、Token 或最后使用时间排序，并按状态筛选。

| 列表项 | 含义 |
| --- | --- |
| 请求数与趋势 | 所选窗口内已结束的逻辑请求，每次请求只计一次 |
| Token ↓ / ↑ | 已记录的输入 / 输出 Token |
| 成功率 | 所选窗口内已结束请求的成功比例 |
| 最后使用 | 保留记录中的最近活动，可能在所选统计窗口之外 |

点 Key 名称或图表按钮查看趋势、模型分布与最近请求。Key 轮换后仍按同一身份归集，撤销的 Key 也保留可查询历史。帮助图标说明数据覆盖；没有记录的用量不会冒充已知的零，已删除的历史不能重新生成。

## 模型 token/s

Models & Routing 在逻辑模型列和每条主用、备用上游线路旁直接显示 token/s。

| 速率 | 计算口径 |
| --- | --- |
| 逻辑模型 | 成功请求的输出 Token 总量 ÷ 总耗时，包含等待与恢复 |
| 上游模型 | 成功上游调用的输出 Token 总量 ÷ 对应调用总耗时，按 Provider 与实际模型归集 |

速率是所选统计窗口内的加权平均，包含等待和传输，不等于模型纯生成速度。悬停可看统计窗口与有效样本数；无有效样本显示 `—`。

## Provider 账户与时间

独立账户各占一条子行；只有确认共享额度的协议连接才合并显示。支持 Codex，以及受支持官方端点上的 Kimi、GLM 和 Z.ai Coding Plan；用量与重置时间以上游返回为准。

| 显示 | 含义 |
| --- | --- |
| Reset | 对应额度窗口的重置倒计时；悬停显示准确时间 |
| 蓝色 Reset | 距离重置不超过 24 小时 |
| 绿色 Reset | 距离重置不超过 1 小时 |
| 橙色待确认 | 时间已到，仍需新用量确认重置 |
| Next | 下次模型目录同步时间 |
| `—` | 上游没有提供可确认的数据 |

额度窗口会分别保留，调用次数、额度单位和百分比不混算。刷新失败时保留上次数据并提示错误。Next 到点后显示同步待执行；暂停同步的 Provider 显示暂停状态。

## 请求与会话

Request 的执行历史与详情默认展开。Session、Provider 和模型页刷新时保留所选请求及滚动位置。更多事件含义见 [Sessions 与请求解释](../session-observability.md)。
