# SmartAPI 1.0.1 — S 形标识 / S mark

更新控制台浅色、深色 Logo 和浏览器图标，使用连续 S 形与斜切端点，替换旧 F 形标识。同步 README／官网流程图中嵌入的产品标识及品牌来源说明。保留原有 112×123 viewBox、炭黑与反白配色。

The console light/dark marks and favicon now use a continuous S with diagonal terminals. Documentation and website diagrams use the same mark. The original viewBox and monochrome palette are retained.

## 安装与升级 / Install and upgrade

```sh
curl -fsSLo compose.yaml https://github.com/hulkbig/smartapi/releases/download/v1.0.1/compose.yaml
docker compose up -d --no-build
```

镜像 / Image: `bighulk/smartapi:1.0.1`, Linux AMD64 / ARM64. Existing `v1.0.0` artifacts remain unchanged.

本补丁仅更新品牌资源和发行版本引用，不改变 API、数据库 schema、凭据、模型、路由或业务行为。已有安装保留数据卷；升级前按[Docker 指南](../guide/docker.md)验证备份，不执行 `down -v`。浏览器若仍显示旧图标，可强制刷新页面。

This patch changes brand assets and release references only. API behavior, database schemas and credentials are unchanged. Keep the existing data volume and follow the [backup and upgrade guide](../guide/docker.en.md). Refresh cached browser assets if the old icon persists.

## 验证范围 / Verification scope

Logo 已通过 SVG XML 检查与本地真实渲染视觉核验。发行门禁覆盖准确提交的产品 CI、AMD64／ARM64 原生镜像安装、重启、备份恢复与漏洞扫描；只有对应 workflow 成功才表示该项完成。本次不将历史性能基线或此前供应商测试声明为 1.0.1 的重新实测。

The mark was checked as SVG XML and visually inspected after rendering. Release acceptance is recorded by the exact-commit CI and native-platform image workflows. Historical performance and provider results are not new measurements for this patch.
