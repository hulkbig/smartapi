# SmartAPI 1.1.2 — 模型路由与请求流转 / Model routing and request traces

Model Routing 页按顺序展示条件分支与默认路由，区分规则的 `enabled` 配置和所选请求的实际命中，并显示 Provider、上游模型及故障后推进条件。

The Model Routing page shows conditional branches in order alongside the default route. A rule's `enabled` configuration remains distinct from the selected request's actual matches. Each step shows its Provider, upstream model and conditions for advancing after a failure.

同页复用真实请求事件图，严格按当前逻辑模型筛选，支持时间范围、每页四条来源的分页、选择具体请求和跳转完整 Request。沿用慢速手动回放、处理中节点边框、终态静止及减少动态效果。

The page reuses the real request event diagram, strictly filtered by the current logical model, with a time range, four sources per page, request selection and a link to full Request details. Slow explicit replay, working-node borders, static terminal states and reduced-motion behavior carry over.

主动选择的请求在新流量进入后保持选中，避免自动刷新打断回放；下拉选择完成后恢复实时更新，同时保留键盘焦点。

Explicit request selection survives incoming traffic so refresh does not interrupt replay. Live updates resume after a selector change while keyboard focus is retained.

## 安装与升级 / Install and upgrade

```sh
curl -fsSLo compose.yaml https://github.com/hulkbig/smartapi/releases/download/v1.1.2/compose.yaml
docker compose up -d --no-build
```

镜像 / Image: `bighulk/smartapi:1.1.2`, Linux AMD64 / ARM64.

沿用已有数据卷；本补丁无需更改数据库结构、协议、凭据或模型配置。见 [Docker 安装](../guide/docker.md)、[升级指南](../guide/docker.md#升级)和 [Model Routing 请求说明](../session-observability.md)。

Keep the existing data volume. This patch requires no changes to the database schema, protocols, credentials or model configuration. See [Docker installation](../guide/docker.en.md), the [upgrade guide](../guide/docker.en.md#upgrade) and [Model Routing request documentation](../session-observability.en.md).
