# SmartAPI 1.0.0 — 首次公开发行 / First public release

SmartAPI 是为 AI Agent 长任务设计的自托管网关。本版本是 `hulkbig/smartapi` 的首次公开发行，提供 Go + SQLite 服务、管理控制台和官方 Agent Skill。

## 功能范围 / Scope

- OpenAI Chat、Responses、Anthropic Messages 接入；逻辑模型、路由、限流等待和有预算的恢复。
- API Key 与受支持的订阅账号接入、请求诊断、额度管理、备份与恢复。
- `smartapi` 命令、`cmd/smartapi` 入口，以及 `skills/smartapi` 中的无第三方依赖 Python 客户端。

SmartAPI provides a self-hosted Go + SQLite gateway, console and Agent Skill for routing, bounded recovery and request diagnostics. Provider capabilities depend on the protocol, route, account permissions and actual upstream behavior.

## 安装 / Installation

```bash
curl -fsSLo compose.yaml https://github.com/hulkbig/smartapi/releases/download/v1.0.0/compose.yaml
docker compose up -d --no-build
```

镜像 / Image: `bighulk/smartapi:1.0.0`（Linux AMD64 / ARM64）。发行附件和镜像需在正式发布后才可下载。
