# SmartAPI 1.1.1 — 流转动效与界面精简 / Clearer request motion

Session、Request 与 Provider 流转默认展示当前或最终状态，结束的请求不再自动回放。手动回放放慢节奏，并明确标注历史过程。传输图标按新事件单次经过，不因轮询、重排或停留而循环发送。

Session, Request and Provider diagrams open at the current or final state. Completed requests no longer autoplay. Explicit replay runs at a readable pace and is clearly labeled. Transfer icons run once per observed event instead of looping or restarting on refresh and relayout.

正在处理的节点使用缓慢呼吸边框：等待准入标记网关，实际调用标记所选 Provider 与连接，客户端开始接收后标记交付节点。上游结束与客户端交付结束分别表达，终态和缺失执行证据不会持续显示处理中。

Slow border pulses identify the recorded work: admission waiting at the gateway, a dispatched call at its Provider and connection, and client delivery at the delivery nodes. Upstream and downstream completion remain separate. Terminal requests and missing execution evidence do not imply ongoing work.

没有实际摘要时省略内容行，移除反复出现的“Content not recorded”和重复说明；保留真实 Request / Response 前缀、候选条件、错误和统计。

Missing excerpts omit the content row. Repeated unavailable-content placeholders and redundant hints are removed while useful excerpts, candidate conditions, errors and statistics remain.

## 安装与升级 / Install and upgrade

```sh
curl -fsSLo compose.yaml https://github.com/hulkbig/smartapi/releases/download/v1.1.1/compose.yaml
docker compose up -d --no-build
```

镜像 / Image: `bighulk/smartapi:1.1.1`, Linux AMD64 / ARM64.

沿用已有数据卷；本版本不改变数据结构、采集开关或已有凭据。见 [Docker 升级指南](../guide/docker.md)及 [Sessions 说明](../session-observability.md)。

Keep the existing data volume. This patch does not change the database schema, capture settings or credentials. See the [Docker upgrade guide](../guide/docker.en.md) and [Sessions documentation](../session-observability.en.md).
