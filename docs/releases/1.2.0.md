# SmartAPI 1.2.0 — 历史用量、模型速度与账户额度 / Usage history, model speed and account quotas

## 控制台 / Console

- API Keys 默认展示近 7 天历史，可切换 24 小时与 30 天。列表包含请求趋势、输入／输出 Token、成功率和最后使用时间，支持排序、状态筛选及详情图表。轮换和撤销保留身份关联的历史；缺失用量与已知零值分开显示。
- 逻辑模型及主用、备用上游模型在列表直接显示 token/s。按成功样本的输出 Token 总量除以总耗时计算，包含等待与传输；无有效样本显示 `—`。
- Provider 按独立账户显示子行；确认共享额度的协议连接合并。支持 Codex 与受支持的 Kimi、GLM、Z.ai Coding Plan 用量。每个额度窗口显示 Reset 倒计时及临近重置配色，Next 显示模型目录同步时间。
- 队列指标更紧凑，菜单悬浮不再撑高行，模型标签保持间距。触屏布局、后台刷新、请求选择与滚动位置更稳定；Request 历史默认展开。
- 请求解释保留未采用路线和历史配置依据，协议连接以标签组织；处理中与已结束状态分别呈现。

- API Keys defaults to 7-day history with 24-hour and 30-day options: request trends, input/output tokens, success rate, last activity, sorting, status filters and detail charts. Rotation and revocation retain identity-linked history; missing usage stays distinct from known zero.
- Logical models and primary/fallback upstream models show token/s directly in lists. Rates divide output tokens by total elapsed time over successful samples, including waiting and transport. Missing samples display `—`.
- Providers use independent account subrows and merge protocol connections only for confirmed shared quota. Codex and supported Kimi, GLM and Z.ai Coding Plan usage include quota Reset clocks and proximity colors. Next shows model catalog synchronization.
- Compact queue metrics, floating menus, spaced route labels and touch layouts improve scanning. Refresh retains request selection and scroll position; Request history opens by default.
- Request explanations retain unused routes from historical configuration, group protocol connections as badges and distinguish working from completed states.

## 安装与升级 / Install and upgrade

```sh
curl -fsSLo compose.yaml https://github.com/hulkbig/smartapi/releases/download/v1.2.0/compose.yaml
docker compose up -d --no-build
```

镜像 / Image: `bighulk/smartapi:1.2.0`, Linux AMD64 / ARM64.

保留原数据卷、模型与账号配置。新统计读取已保留的历史，不补造已删除记录；旧记录缺少可用 Token 或时长时可能显示 `—`。构建工具链更新至 Go 1.26.11。升级前按 [Docker 指南](../guide/docker.md#升级)备份；需要请求历史时显式使用 `-backup-history`。

Keep the existing data volume, models and account configuration. New metrics use retained history without reconstructing deleted records; older records with insufficient token or timing evidence may display `—`. Builds use Go 1.26.11. Follow the [Docker upgrade guide](../guide/docker.en.md#upgrade), explicitly using `-backup-history` when request history must be included.
